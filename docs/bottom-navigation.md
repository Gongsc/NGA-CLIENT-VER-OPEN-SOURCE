# 首页底部导航

首页已移除侧栏，改为固定顺序的「首页、历史、消息、我的」四个一级入口。保留原首页板块分类、搜索、论坛收藏同步与管理；账号功能集中在「我的」，回复通知和短消息移到「消息」顶部 Tab。

## 交互

- 底栏复用发表主题按钮的滚动判断：用户向下浏览累计超过 12dp 时收起，反向滚动或回到顶部时恢复；惯性滚动不触发切换。切换一级页面或板块分类时恢复显示，系统导航安全区始终保留。
- 「我的」导航图标优先使用当前账号头像。未登录或头像地址为空时显示默认人物图标；图片加载中或失败时使用默认头像。遵守现有头像加载策略。
- 切换一级页面保存列表滚动位置；非首页按返回键回到首页。
- 本地历史按浏览日期分组，保留原有主题编号和阅读页数。旧记录缺少浏览日期时显示「更早」，不使用发帖日期冒充浏览时间。长按删除单条、清空全部均需确认。
- 回复通知保留跳转到对应回复的参数；短消息提供会话详情、写短消息、下拉刷新及分页。未登录显示登录入口。未读角标沿用现有回复通知计数，不推算服务端未提供的短消息未读数。
- 消息请求固定使用发起时的 Cookie，切换账号或同一账号重新登录均取消旧请求并清空列表。响应同时验证账号、会话及请求代次，失败保留当前已加载内容。未读回复查询至多追加一次历史查询。
- 字体与阅读大小入口移到「外观与布局」，仍复用原阅读设置页面和偏好键；返回时回到外观页。

## 验证

单元测试覆盖账号切换、会话更新、消息分页去重、失败重试、未读回复合并和旧历史记录兼容。设备测试覆盖四个导航入口、消息登录状态、滚动显隐、共享滚动判断、原论坛收藏操作以及外观页中的阅读大小入口。设备测试使用离线合成数据。
