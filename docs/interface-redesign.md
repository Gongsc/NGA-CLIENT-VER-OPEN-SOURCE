# 界面布局与外观重构

## 布局

版块列表提供标准与紧凑模式。紧凑模式采用自适应双列、小图标、单行名称与分隔线，条目最小高度为 56dp，图标操作保留至少 48dp 的点击区域。大字体或窄屏时减少列数，避免通过缩小文字维持列数。首页与目录共用密度设置，并通过应用私有偏好数据持久化。密度切换仅保留在“外观与布局”设置中；首页列表上方不再显示“论坛收藏／版块目录”标题与切换行，目录筛选框下方也移除版块数量与切换行，列表直接接续上方内容。收藏管理仍通过顶部“首页操作”菜单进入和完成。

刷新、同步、重试、恢复默认与引用等操作使用统一线性图标，提供内容说明和长按提示。楼层客户端来源使用 Android、Apple、Windows 或通用设备图标，随主题调整颜色，并保留点击查看原始客户端信息的功能。恢复默认与取消论坛收藏仍保留确认步骤。

阅读页参考 [Nodyssey 的主题详情布局](https://github.com/5151561/nodyssey)，采用右下角悬浮控件：竖排页码、上一页和下一页，下方是带文字的回复按钮。页码入口保留按页码、按楼层跳转，“回到首页”放在跳转弹窗；边界页与翻页动画期间禁用相应翻页按钮。向下阅读时收起上一页、下一页并将回复按钮缩为图标，向上回看或返回列表顶部时展开，页码入口始终可用；回复按钮保持底部位置不变，列表末尾留白按展开尺寸保留，避免收起动画引起正文跳动。滚动状态通过现有共享 ViewModel 从正文 Fragment 传到分页宿主，只响应当前页，程序跳转与惯性滚动不改变控件展开状态。左手模式将整组控件镜像至左下角，系统手势区域与横屏安全区域由 Scaffold 处理。配色跟随当前主题，点击区域至少 48dp，列表末尾按控件高度及系统字号留白，确保最后一条回复能够滚动到悬浮控件上方。Android 端按现有 Compose 架构独立实现。

主题列表的“发表主题”同样参考 Nodyssey：向下阅读时缩为编辑图标，向上回看或返回顶部时展开为图标与文字；收起后保持原位置并可继续发帖。沿用左手模式、主题配色、无障碍标签和列表末尾留白，不改动列表加载与翻页。主题列表和正文共用滚动方向识别，累计 12dp 实际手势滚动后切换，惯性滚动不触发切换。

## 配色

原 Compose 主题固定使用一组颜色，没有读取原有配色设置。新外观配置统一提供四套主题，每套包含浅色和深色的背景、内容表面、文字、分隔线及强调色；旧棕色、绿色和黑色偏好分别映射为暖砂、松绿和石墨。

“外观与布局”提供主题、深色模式及列表密度配置，修改后立即更新当前 Compose 界面。状态栏图标同时调整深浅，默认恢复为松绿、紧凑和跟随系统。

正文 WebView 的容器、链接、引用和代码区域使用相同主题色，保留帖子自行指定的彩色文字。Android 13 及以上关闭正文 WebView 的额外自动深色处理，避免对已经着色的正文重复变色。

## 验证

- 单元测试覆盖旧偏好映射、主题间背景差异、正文与次要文字的对比度，以及网页主题注入保留原始内容。
- 设备测试验证实际像素随主题变化、正文 DOM 中的深色配色、密度切换与保存、悬浮分页位置、首末页禁用状态及跳转。
- 悬浮控件在 Android 12 模拟器验证浅色右手模式、深色左手模式及两倍字号，覆盖回复回调、按楼层跳转、最后一条回复滚出控件遮挡范围，以及上下滑动收起／展开、回复按钮缩小后仍可点击且底部位置不变；另以离线数据验证实际 Fragment 宿主中的滚动联动；截图为 `reader-floating-light.png` 与 `reader-floating-dark-left-large.png`。
- 原有登录、编辑器、论坛收藏、正文高度及链接分发测试继续执行。
- 960×600 横屏、1.5 倍字体与关闭动画配置下，四项新布局检查通过。
- 外观变更后旧网页颜色缓存按需重建，避免后续正文转换读取到失效缓存。
- 实际界面截图保存在 `docs/previews/implemented/`，使用示例数据，不包含真实账号内容。

## 侧边栏与设置整理

侧边栏分为账号头部（头像、昵称、UID、切换与添加账号）、账号（消息与我的内容两组卡片）、论坛工具和底部应用入口四级，避免个人主题、消息与应用配置混排。外观与布局仅保留侧栏应用组入口，设置页不再重复外观入口；账号登录和切换集中在账号区。

设置主体和字号调整页使用 NgaTheme 与 Material 3 组件，浅色、深色及四种配色同步生效。设置保留原偏好键名，分类、开关、选择弹窗与缓存确认均使用主题颜色。选项较多的弹窗支持滚动，设置分组标题具有标题语义。

导航与设置检查覆盖入口去重、分组顺序、配置持久化、通知声音依赖、缓存确认和实际设置页面跳转。另在 375 dp 宽的小屏和横屏、2.0 倍系统字体及关闭动画的条件下验证侧栏与设置操作。
